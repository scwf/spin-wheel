# 轮盘转抽奖

一个可定制、多主题的转盘抽奖应用，专为公平随机的活动设计。

## ✨ 功能特性

- **轻松定制**: 只需修改HTML文件中的`OPTIONS`数组，即可轻松配置抽奖选项和分类。
- **分类展示**: 在侧边栏清晰地按类别展示所有抽奖项目，一目了然。
- **流畅动画**: 基于 `requestAnimationFrame` 实现，确保转盘转动动画平滑自然。
- **多种主题**: 内置四个不同视觉风格的主题，可根据喜好选择。
- **零依赖**: 纯粹使用HTML, CSS和原生JavaScript编写，无需任何服务器或构建步骤，直接在浏览器中打开即可使用。

## 🎨 可用主题

项目内包含四个独立的HTML文件，每个文件代表一个大模型生成的视觉主题（推荐ChatGPT生成的）：

1.  `ChatGPT-index.html`: 科技感的深色主题，界面富有现代感。
2.  `Kimi-index.html`: 充满活力的紫色渐变主题，色彩鲜明。
3.  `Qwen-index.html`: 创意风格的多彩渐变主题，视觉效果丰富。
4.  `Gemini-index.html`: 简约干净的主题，采用独特的文字环绕式轮盘。

## 🚀 如何使用

1.  **选择主题**: 从上述四个`.html`文件中选择一个您喜欢的主题，直接用浏览器打开它。
2.  **修改选项**:
    - 用代码编辑器打开所选的`.html`文件。
    - 找到`<script>`标签内的`const OPTIONS`数组。
    - 按照现有格式（分类和选项）修改为您需要的内容。
3.  **开始抽奖**: 保存文件后，在浏览器中刷新页面。点击“开始抽取”按钮或轮盘中心即可开始抽奖。
